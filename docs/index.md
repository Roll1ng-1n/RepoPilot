# RepoPilot

RepoPilot provides bounded repository engineering with explicit plans, verification and resumable artifacts.

Follow the [installation and first-run guide](https://github.com/Roll1ng-1n/RepoPilot#readme), then [inspect](repopilot-inspect.md) or resume a persisted run. See [capabilities](repopilot-capabilities.md), [benchmark](repopilot-benchmark.md), [release validation](repopilot-release.md) and [current evidence](evidence/next-stage/report.md).

The fixed mini-SWE-agent v2.4.6 base and MIT attribution are retained. [Upstream overview](upstream-overview.md) describes that project, rather than RepoPilot-specific claims.
